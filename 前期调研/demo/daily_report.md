## 方法说明

- 到手价 = 商品原价 + 打包费 + 配送费 - 商家优惠 - 平台券 - 会员权益 - 支付优惠。
- 价差 = 京东到手价 - 最低竞对到手价。正数表示京东更贵，负数表示京东更便宜。
- 目标价 = 竞对到手价 - 目标优势。必要补贴 = max(0, 京东补贴前价格 - 目标价)。超补 = max(0, 实际补贴 - 必要补贴)。
- 价差分解把总价差拆到菜单价、包装费、配送费、商家活动、平台券、会员、支付七项，用来定位可执行的动作。
- 两类优先级分别 = 价差或超补 × log(1 + 月 GMV)，各自归一化到 0 到 100。它用于排序，不直接代表业务收益。
- 超补金额按单次观测计算，乘订单量才能估算月度可节省金额。
- 本报告使用模拟数据，只演示计算和报告格式，不构成任何真实商户或平台的价格结论。
