## 二、为什么淘宝不能照搬京东/美团

京东和美团走的是「u2 读屏拿节点 bounds → 精确点击 → guardMainPath 白名单断言」。淘宝这条路走不通：

- **原生页（Flutter 自绘）**：u2 `dumpWindowHierarchy` 返回 0 节点。
- **H5 页（`com.taobao.browser.BrowserActivity`）**：返回 1 个节点、0 条文字。

所以淘宝整条链路只能用视觉定位，且**禁止使用 `guardMainPath`**。

### 2026-11-09 深夜改坏的准确位置

对比日志时间戳可以确认：

```
11-09 22:04  taobao-flow.ts 跑通：tap 全部成功，无一条"偏离主链路"
11-09 23:01  同一文件被修改，加入 guardMainPath 检查
11-10 08:06  第二天：每步都输出"点击后偏离主链路 unknown 立即返回"
```

`guardMainPath` 要求读到页面节点才判定在主链路，而淘宝 Flutter 页永远读到 0 节点，于是每一步都被判 `unknown` 并 `back` 掉，把原本能跑的链路整体废掉。**这是那次"连续十小时把链路改错"的具体位置。**

## 三、四个关键坑（都已修复）

### 1. yadb 中文输入：参数写错，不是不可用

设备上 `/data/local/tmp/yadb` 一直在（14431 字节）。正确调用：

```
adb shell app_process -Djava.class.path=/data/local/tmp/yadb /data/local/tmp \
  com.ysbing.yadb.Main -keyboard '板烧鸡腿堡'
```

类名是 `com.ysbing.yadb.Main`，工作目录是 `/data/local/tmp`。用 `com.android.commands.yadb.YadbMain` 配 `/system/bin` 会报 `Aborted`。成功标志是输出 `Copy text:true`。

### 2. 视觉定位超时：默认值对本地 2B 模型太小

`src/infra/model.ts` 里改了三处（已提交）：

| 项 | 原值 | 新值 |
|---|---|---|
| `AbortSignal.timeout`（call 层） | 35_000 | **90_000** |
| `MIDSCENE_MODEL_TIMEOUT` | 20_000 | **60_000** |
| locate 内部缩图宽度 | 640 | **800** |

改之前视觉定位大量 `model_location_failed`，改之后返回时间稳定在 1.5～4 秒。

### 3. 视觉定位必须配页面结构硬约束

搜索结果页顶部有「超抢手 爆款好价」广告位，里面也含「麦当劳」字样，模型会优先选中它。解决办法是给每次定位加 **y 坐标区间**，把广告区排除掉。例如门店卡片限定 `yMin = 0.30H, yMax = 0.65H`。

### 4. 同页近似品名：2B 模型无法区分，必须用相对比例坐标

店内搜索「板烧鸡腿堡」，结果页有两个高度相似的条目：

```
第 1 行  双层板烧鸡腿堡       ¥34.5   加号在 0.214H
第 2 行  板烧鸡腿堡           ¥26.5   加号在 0.3875H   ← 目标
第 3 行  双层板烧鸡腿堡三件套  ¥35.9起  [选套餐]
第 4 行  板烧鸡腿堡套餐       ¥42起    [选套餐]
```

模型连续 4 次都返回第 1 行的加号 (1188,606)，无论提示词怎么强调都不是「双层」。最终改用**标定的相对比例坐标**：

```ts
const SHOP_SEARCH_ADD_BTN = {xRatio: 0.938, yRatio: 0.3875};
```

换机型或淘宝改版后需要重新标定。

## 四、完整链路与每步约束

| 步 | 动作 | 定位方式 | 约束 |
|---|---|---|---|
| 0 | 唤醒屏幕 + `svc power stayon true` | adb | 息屏时截图约 20KB 全黑，视觉定位必然错 |
| 1 | 冷启动淘宝 | `am start -S` | 等 **20 秒**，冷启动期间占 CPU 会拖慢模型 |
| 2 | 首页 →「闪购外卖」tab | 视觉 | y 120～300 |
| 3 | 点搜索框 | 视觉 | y 260～430 |
| 4 | yadb 注入「麦当劳」→ 点搜索 | 视觉 | y 140～360 |
| 5 | 结果页 → 目标门店卡片 | 视觉 | y 0.30H～0.65H（避开广告位） |
| 6 | 门店页下滑，让顶部展开完整「搜一搜」 | swipe | 刚进店只有小放大镜，无法定位；下滑后才有完整搜索框 |
| 7 | 点「搜一搜」 | 视觉 | y 60～430 |
| 8 | yadb 注入「板烧鸡腿堡」→ 点搜索 | 视觉 | y 60～540 |
| 9 | 点目标单品加号 | **相对比例坐标** | (0.938W, 0.3875H) |
| 10 | 若仍在详情页未加购，补点「加入购物车」 | 视觉，只试 1 次 | 搜索结果页的「+」点中图标会直接加购，点偏只进详情页 |
| 11 | 点「去结算」 | 视觉 | y > 0.85H |
| 12 | 读结算页字段 | 视觉 JSON 逐项读 | 每次只问一个金额，复杂嵌套 schema 会让 2B 模型输出不合法 |

## 五、尚未解决的问题

### 1. 首轮模型冷启动失败（主要稳定性短板）

3 轮连测里第 1 轮必失败，`flash-tab` 连续 3 次 `model_location_failed`，每次卡满 62 秒；第 2、3 轮都在 5 秒内成功。已加模型预热（一次极小文本请求），但本次验证仍失败一次，说明预热不够或时机不对。

**建议**：预热改为**两次**，或预热后先做一次真实 locate 试跑；也可考虑把 `MIDSCENE_MODEL_TIMEOUT` 再提到 120 秒。

### 2. 淘宝 source 仍是 `restricted`

`android-sources.json` 里 `taobao_instant` 缺 `access.writtenPermission` 字段，`permitted()` 返回 false，所以还不能进调度器。补这个字段需要确认授权表述。

### 3. 尚未接入调度器

`src/adapters/taobao-collect.ts` 目前是独立可运行模块，还没注册成 `Collector`、没接 `live-progress` 进度上报，所以 `/bd` 勾选淘宝仍会返回"未接入"。

### 4. 购物车需每轮清理

不清会跨轮累加，导致金额翻倍。当前用「详情页数量控件减号 ×3」清理，位置 `(0.800W, 0.4764H)`，写入 `.runtime/stability-taobao.ts`。

## 七、安全边界

- 采集链路**绝不点击「立即支付」**，代码中不存在该动作。
- 每轮采完停在结算页，退出用返回键。
- 结算页金额为只读，不提交订单。
