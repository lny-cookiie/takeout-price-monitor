# 约束与合规

这一份是「能不能卖、怎么卖」的前置条件。任何对外演示、报价、交付之前，先按最后一节的检查表过一遍。这里不是法律意见，具体合作需要律师出具书面意见。

## 一、法律红线（有真实判例支撑）

### 刑事风险：非法获取计算机信息系统数据罪

2026 年 6 月浙江平安网报道的案子：四个人用爬虫脚本破解平台验证码、虚设登录身份，爬取并售卖商品详情数据 11 万余条，累计获利 4.4 万余元，被判处有期徒刑九个月到一年二个月，并处五千到一万元罚金（[出处](http://www.pazjw.gov.cn/shuoan/202606/t20260619_31736178.shtml)）。关键点在于「绕过技术防护」和「未授权获取并售卖」，获利金额小并不免责。

对产品的约束：不破解验证码、不伪造登录身份、不切换设备指纹绕过风控、不把平台数据对外售卖。遇到验证码只能停下来等人工处理。

### 民事风险：不正当竞争

律师案例文章记录：一位创业者做本地生活聚合小程序，爬取本地三大外卖平台的商家信息做比价，被头部平台起诉不正当竞争、索赔 20 万元，最后调解赔偿 8 万元；文章还提到大众点评诉百度地图案，法院认定全量搬运商家信息用于同类产品构成不正当竞争（[出处](https://m.wuhanlihunlvshi.com/cases/2351.html)，属案例文章，供参考）。《反不正当竞争法》第十二条对互联网领域的不正当竞争有专门规定。

对产品的约束：即便数据在页面上公开，全量抓取并用于与平台竞争的产品，也有很高的民事赔偿风险。产品只做客户授权的、最小必要的、内部决策用途的采价，不做「平台替代品」。

### 个人信息保护

《个人信息保护法》和《数据安全法》要求最小必要、告知同意、不得超范围使用。外卖结算页包含收件人姓名、电话、地址，属于个人信息。

对产品的约束：采价只读取价格、门店、商品、费用行；截图证据必须把顶部地址和收件人区域涂黑；不存储、不导出、不训练个人信息；日志里对手机号和地址做脱敏。

## 二、平台约束

1. 平台用户协议和 robots 协议通常禁止自动化访问、批量抓取和商业性使用，账号可能被限制或封禁。
2. 平台风控会识别高频、机械化的操作模式，验证码、滑块、设备校验会随频率升级。
3. 平台会频繁改版，任何依赖页面结构的自动化都会周期性失效，这不是技术问题而是持续成本。
4. 部分平台自身向商家提供免费或官方的数据工具，会压缩第三方付费工具的空间。

## 三、可以做什么，不可以做什么

| 可以做（需合同和授权） | 不可以做 |
| --- | --- |
| 客户书面授权后，为其内部决策采价 | 未经授权采集并转售平台数据 |
| 只采集价格、门店、商品、费用等必要字段 | 采集收件人姓名、电话、地址等个人信息 |
| 低频、按需、指定城市和门店的采价 | 大规模全量抓取、建立平台替代数据库 |
| 验证码出现时停下等人工处理 | 自动识别、点击或破解验证码 |
| 使用客户自己的账号和设备 | 伪造身份、切换设备指纹、绕过封禁 |
| 保存脱敏后的结算页证据 | 把平台原始数据或截图对外分发 |
| 与平台或持牌数据服务商合作取数 | 用爬取数据做与平台竞争的产品 |

## 四、对外销售前的合规检查表

- [ ] 有律师出具的书面合规意见，明确业务模式和数据范围。
- [ ] 与客户签数据处理协议，写明授权来源、使用目的、保存期限和删除机制。
- [ ] 个人信息零留存：截图涂黑、日志脱敏、证据库访问受控。
- [ ] 验证码与账号异常有人工介入流程，不设自动绕过。
- [ ] 采价频率有上限，按平台和时间段控制，遇到风控立即停。
- [ ] 数据只用于客户内部决策，合同禁止转售和对外分发。
- [ ] 有失败和异常的处理记录，客户可追溯每一次采价。
- [ ] 对外宣传不使用「破解」「绕过」「全量监控」等表述。

## 五、风险登记

| 风险 | 可能性 | 影响 | 缓解措施 |
| --- | --- | --- | --- |
| 账号被封 | 中 | 采集中断、客户不满 | 低频、固定设备、冷却、备用账号 |
| 平台改版导致链路失效 | 高 | 维护成本上升 | 知识库、视觉兜底、快速适配流程 |
| 民事索赔 | 中 | 赔偿和声誉损失 | 客户授权、最小必要、律师意见 |
| 刑事风险 | 低到中 | 负责人刑责 | 不碰验证码、不伪造身份、不倒卖数据 |
| 个人信息泄露 | 低 | 高额处罚 | 涂黑、脱敏、最小化、访问控制 |
| 客户数据被转售 | 低 | 违约和连带责任 | 合同禁止、技术审计 |
